# ok-nte 插件：消耗体力培养角色

与异象追猎/巡礼同级的独立任务 `CultivationGoalTask`，以插件形式安装，**不随 ok-nte 宿主更新被覆盖**。

## 安装（Add from GitHub）

1. 打开 ok-nte 的「插件」页，点 **Add from GitHub**
2. 输入本仓库地址：`Camellune/ok-nte-cultivation-goal`
3. 选择最新 release 里的 `cultivation_goal_v*.okscript` 安装即可

> 也可在本页 [Releases](../../releases) 手动下载 `.okscript`，再从插件页「本地文件」安装。

## 功能

- 任务开始读一次养成指南页「所需材料」缺口（模板识别 + 档位判色），支持异能/等级 BOSS/弧盘/周本四类行
- 每局读取奖励掉落累计账本，日志输出 `+X 有N/M 还差Y`；缺口清完自动换下一个副本
- 副本优先级：**周本 > 世界BOSS > 异能 > 弧盘**
- 连打全自动：当前副本产出不足以覆盖缺口时自动连打（内置 20 局保险丝），够了自动换副本
- 支持双倍体力；比例读数与材料槽位交叉校验，读数残缺自动回页复核
- 注册为「日常」子项，可随日常流程一起跑

## 配置（仅 3 项）

| 配置 | 说明 |
|---|---|
| 目标消耗体力 | **今日最低消耗量**（满足日常活跃度即可），不是截断条件。只要还缺材料且体力够一次最便宜副本（40），就会继续刷 |
| 周本刷取开关 | 开=优先刷满本周异象巡礼，关=直接刷其它材料 |
| 掉落统计 | 日志输出掉落了什么材料、掉了多少、还差多少 |

- **v1.5.10.1**：跟随宿主 **v1.5.10**（前三段对齐），修三处「卡住 / 报错数」。
  ① **周本副本没解锁会卡死**：地图详情页右下角按钮是「追踪」而不是「传送」时，旧版会一直等传送按钮，
  10 秒超时 × 重试后整轮周本失败。现在开打前逐个点开周本目标、**只读按钮不点它**，读到「追踪」就记日志
  并从目标清单里剔除；读不出字的目标按已解锁处理（宁可多试一次也不误杀能打的副本）。
  ② **剩余体力报错数**：账本模式只在开局读一次面板，中途靠本地扣账，于是界面和外层自动化一直显示开局那个
  数字（实测停在 186，实际只剩 6）。现在每轮把账本体力写回「当前体力」，并在判定「体力不够下一次」收工前
  **回面板实测一次**，判定与上报都用实测值；日志里会有 `收工前复核体力: 账本 X → 实测 Y`。
  ③ **任务被单开成一栏**：宿主加载插件后会执行 `task.group_name = script_name`，改用 `FixedGroup`
  数据描述符吞掉这次赋值，任务留在「体力本」分组。

- **v1.5.9.4**：**空幕接管**。空幕在刷取优先级里排最后，但它没有次数上限 —— 其它行都推不动时
  （材料已满，或周本还缺料但本周次数已用完），只有它能把剩余体力换成材料。以前是把任务类型切给
  原版 `AnomalyTask.do_run` 一把跑完：**序号恒为 1**、掉落不进账本、失败分不清第几局。现在只借原版
  的入场导航，循环与记账自己做：按「空幕」页缺口挑副本（钟表把戏 / 雕塑展馆 / 纬线织机 / 守卫萝卜），
  逐局输出「空幕第 n 局掉落: 钟表把戏×2」，读不出缺口就不刷（刷错副本白花 40 体力）。
  顺带修正：周本次数用完的行算「已达上限」，不再每轮白跑一趟巡礼才跳过。

- **v1.5.9.3**：材料缺口按 **3:1 合成折算**。异能/弧盘同一条目有三档材料（绿→蓝→紫），
  3 个低档可以合成 1 个高档，但旧版逐槽比 `拥有 ≥ 需要`，于是 `48/8 + 32/40 + 16/13` 这种
  「低档堆了一堆、高档只差几个」的行会被一直判成缺料，继续白刷体力（实例：差 1 个蓝却按
  缺 8 走了双倍，多花 40 体力）。现在每档先留够自己的需求，余量按 3:1 往上折，再判够不够；
  日志同时输出「合后」拥有量，能直接对账。折算只在本行内进行，不跨副本。
